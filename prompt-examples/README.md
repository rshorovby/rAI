# Примеры промпта разбора

Снимок того, что уходит в Gemini вместе с видео. Собрано текущим `build_system_prompt` + `build_analysis_prompt`. В рантайме не читается.

Сценарий: игрок на русском выбрал подачу, «смотреть технику», комментарий «вторая подача, снимал сбоку». Есть профиль, прошлый разбор подачи и активный фокус. Эталона тренера нет.

| Файл | Куда в API |
|---|---|
| `serve-returning-player-system.txt` | `system_instruction` |
| `serve-returning-player-user.txt` | текст user-сообщения; рядом отдельным `Part` идёт файл видео |

Каталог упражнений в проде длиннее (до 40 id). Здесь три строки, чтобы пример был короче. Wiki-страницы в system вставлены целиком.
