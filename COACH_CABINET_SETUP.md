# Пошаговая настройка тренерского кабинета (Forum)

После этих шагов каждое видео игрока будет попадать в супергруппу: тема на игрока → видео + AI-разбор. Тренер пишет дополнения свободно в теме.

---

## Что уже сделано в коде

- Игрок сразу получает AI-разбор и может общаться с ботом.
- Тот же разбор параллельно падает в кабинет тренера (тема на игрока).
- Под AI-черновиком — кнопки оценки: **Ок / Дополнил / Мимо**. Комментарий тренера игроку сохраняется рядом с черновиком как эталон.
- Тренер пишет в тему **любые сообщения** — каждое уходит игроку отдельным комментарием (без кнопок send/replace).
- У игрока кнопка «Написать тренеру» — сообщения пересылаются в ту же тему.
- В тему также приходят lifecycle-уведомления: `/start`, онбординг, загрузка видео, AI-разбор, повтор по фокусу, оценка разбора, вопросы к боту, дата тренировки, check-in, напоминания, ошибки/ретраи, сброс профиля.

Осталось **один раз** оформить Telegram-группу и прописать ID в `.env` на сервере.

---

## Шаг 1. Узнать user_id тренера

1. Тренер пишет [@userinfobot](https://t.me/userinfobot) (или `@getidsbot`).
2. Скопируйте число `Id` — это `COACH_USER_IDS`.

Ваш admin id (если уже есть в `ADMIN_USER_IDS`) можно тоже добавить в `COACH_USER_IDS`, если сами будете жать кнопки.

---

## Шаг 2. Создать супергруппу-кабинет

1. Telegram → **New Group** → название, например `RallyMind · Кабинет тренера`.
2. Добавьте пока себя.
3. Откройте профиль группы → **Edit** → **Topics** → **Enable** (Forum / темы).
4. Добавьте **штатного тренера** в группу.

---

## Шаг 3. Добавить бота администратором

1. В группе: **Add members** → найдите вашего бота RallyMind.
2. Профиль группы → **Administrators** → **Add admin** → бот.
3. Включите права минимум:
   - **Manage Topics** (управление темами) — обязательно;
   - **Post Messages**;
   - **Delete Messages** (желательно).
4. Сохраните.

Важно: бот должен быть **админом**, иначе не создаст темы и не увидит ответы тренера в топиках (Group Privacy).

---

## Шаг 4. Узнать `chat_id` супергруппы

Вариант A (проще):

1. Добавьте в группу [@getidsbot](https://t.me/getidsbot) или перешлите любое сообщение из группы боту `@userinfobot` / `@RawDataBot`.
2. Нужен id вида `-100xxxxxxxxxx` — это `COACH_FORUM_CHAT_ID`.

Вариант B (через API):

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getUpdates"
```

Напишите что-нибудь в группе и найдите `"chat":{"id":-100...}`.

---

## Шаг 5. Прописать на VPS в `.env`

```bash
ssh -i ~/.ssh/digitalocean_rallyai root@ВАШ_IP
nano /home/rallyai/rAI/.env
```

Добавьте (подставьте свои числа):

```env
COACH_FORUM_CHAT_ID=-100xxxxxxxxxx
COACH_USER_IDS=123456789
```

Несколько тренеров: `COACH_USER_IDS=111,222`.

Сохраните. Перезапуск:

```bash
systemctl restart rallyai
systemctl status rallyai --no-pager
journalctl -u rallyai -n 20 --no-pager
```

В логах **не** должно быть: `COACH_FORUM_CHAT_ID не задан`.  
Если Forum недоступен, будет ошибка `create_forum_topic` — проверьте Topics и права бота.

---

## Шаг 6. Проверка end-to-end

1. С тестового аккаунта игрока отправьте боту короткое теннисное видео.
2. После уточнения удара/акцента игрок получает ack → через ~минуту **AI-разбор** и кнопку «Написать тренеру».
3. В кабинете должна появиться **тема** `Имя · user_id` с карточкой, видео и AI-разбором.
4. Тренер пишет любой текст в тему → игрок получает «Сообщение от тренера» в личку.
5. Можно писать несколько сообщений подряд — лимита нет.

Если тема не создалась — смотрите `journalctl -u rallyai -n 50` и права `Manage Topics`.

---

## Как тренеру работать каждый день

| Действие | Как |
|----------|-----|
| Новый разбор | Тема игрока: видео + AI-разбор (уже у игрока) |
| Оценить AI | Кнопки под черновиком: **Ок** / **Дополнил** / **Мимо**. Если не «Ок» — можно теги |
| Дополнить | Просто написать в тему — уйдёт игроку и сохранится как эталон правки |
| Несколько комментариев | Пишите сколько нужно — ограничений нет |
| Игрок написал | Сообщение «💬 Сообщение от игрока» в той же теме |

AI-разбор и комментарии тренера **не склеены** в один отчёт: игрок уже общается с ботом по AI, тренер подключается когда удобно.

---

## Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| Игрок получил AI, в группе пусто | `.env`: `COACH_FORUM_CHAT_ID`, `systemctl restart rallyai` |
| `create_forum_topic` / CHANNEL_FORUM_MISSING | Topics не включены |
| Бот не создаёт темы | Нет права **Manage Topics** |
| Сообщение тренера не уходит игроку | Бот не админ / user_id не в `COACH_USER_IDS` |
| Видео не прикрепилось | Редкий сбой file_id — попросить игрока прислать снова |

---

## Локальный `.env` (если тестируете с Mac)

Те же переменные, что на VPS. Кабинет один — и локальный, и прод-бот не должны работать с одной группой одновременно (конфликт getUpdates). Для продакшена кабинет настраивается **только на VPS**.
