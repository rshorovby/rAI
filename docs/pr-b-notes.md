## B8. Follow-up

`build_follow_up_system_prompt` не читает поля JSON. В диалог уходит весь markdown отчёта одной репликой (`analyzer.chat`, первый user-turn). Таймкоды, «(гипотеза)» и «Недостаточно данных» — обычный текст этой реплики. Follow-up, английский промпт и `SKILL_KEYS` не менялись.

## Что видит старый парсер

Блок «Метаданные» по-прежнему JSON с четырьмя осями. Для подачи `leg_drive` записывается как `footwork`. `toss`, `balance` и пустые значения в этот блок не попадают. `primary_segment = none` становится `null`. У `focus_checks` нет `evidence`. У `findings` нет `t` и `issue_tags`.

Сырой JSON лежит в `logs/analysis-runs/` вместе с промптом без видео, хэшами схемы и блоков, проверками, повторами, токенами и стоимостью.
